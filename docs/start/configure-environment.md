# Configure the environment

## The `.env` file

Laravel reads per-environment settings from `.env` at the project root. It is **git-ignored**; `.env.example` is the committed template.

Open `.env` and set:

```ini
APP_NAME="School API"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000
APP_TIMEZONE=UTC
APP_FRONTEND_URL=http://localhost:5173

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=school_api
DB_USERNAME=root
DB_PASSWORD=

MAIL_MAILER=log
```

| Key | Meaning |
|---|---|
| `APP_KEY` | encryption key; already generated by the installer (`php artisan key:generate` otherwise). Never share it |
| `APP_DEBUG` | detailed error pages. **Must be `false` in production** |
| `APP_URL` | used when Laravel builds absolute URLs |
| `APP_TIMEZONE` | keep **UTC**; convert to local time only when displaying |
| `APP_FRONTEND_URL` | our own key: where the SPA runs (used in emails and CORS) |
| `DB_*` | database connection |
| `MAIL_MAILER=log` | emails are written to `storage/logs/laravel.log` instead of being sent |

::: tip Timezone
Recent Laravel versions read `APP_TIMEZONE`. If your `config/app.php` has `'timezone' => 'UTC'` written directly, leave it: UTC is what we want. Stored times are then always UTC, and a Manila user sees them converted in the UI.
:::

## Create the database

In your database client, or in the terminal:

```bash
mysql -u root -p -e "CREATE DATABASE school_api CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

Then create the default tables (users, cache, jobs, sessions):

```bash
php artisan migrate
```

## Keep `.env.example` up to date

Every time you add a key to `.env`, add it to `.env.example` with a safe placeholder, so a teammate who clones the project knows what to fill in:

```ini
REFRESH_TOKEN_PEPPER=            # php -r "echo rtrim(strtr(base64_encode(random_bytes(64)), '+/', '-_'), '='), PHP_EOL;"
AUTH_TRUSTED_ORIGINS=http://localhost:5173
```

## Git ignore

The default `.gitignore` already excludes `.env`, `vendor/` and `node_modules/`. Add the files we'll create later:

```ini
/storage/keys/*
!/storage/keys/.gitignore
/docs/.vitepress/cache
/docs/.vitepress/dist
```

## Check it works

```bash
php artisan migrate:status
```

lists the default migrations as `Ran`. Open the `school_api` database in your client: you should see `users`, `cache`, `jobs`, `sessions` and more.
